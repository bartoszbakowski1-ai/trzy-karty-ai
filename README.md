# 3 karty, dzięki którym AI zna Twój biznes

To darmowy pakiet z live **"Zbuduj własny system AI"** ([bartbakowski.com/webinary](https://bartbakowski.com/webinary)).

W środku masz przewodnika, który **przeprowadzi Cię przez zbudowanie 3 kart kontekstu**:

- **Karta strategiczna** - kim jesteś, do kogo mówisz, co sprzedajesz.
- **Karta wizualna** - jak wygląda Twój świat (kolory, fonty, nastrój).
- **Karta głosu** - jak AI ma pisać w Twoim imieniu.

Raz je robisz, a AI przestaje zgadywać: zna Twój biznes i brzmi jak Ty. W każdej rozmowie, nie tylko pod stronę.

---

## Jak zacząć (3 kroki)

### 1. Pobierz ten folder
Na górze strony GitHub kliknij zielony przycisk **Code -> Download ZIP**. Rozpakuj na pulpicie.

### 2. Otwórz go w Claude Code
Jeśli nie masz jeszcze Claude Code, na live pokazuję, jak go zainstalować (to jedna komenda). Otwórz w nim ten folder.

### 3. Napisz: `zacznijmy`
I tyle. Reszta dzieje się w rozmowie. Claude przywita Cię, wytłumaczy plan i poprowadzi krok po kroku, jedno pytanie po drugim. Zajmie to 20-30 minut. Wypełnione karty zapisze w folderze `karty/`.

---

## Nie masz Claude Code? Zrobisz to też w zwykłym chacie

Działa też w aplikacji Claude albo w ChatGPT. Otwórz plik **`START-w-chacie.md`** i wklej jego treść do chatu. Przewodnik ruszy tak samo, tylko karty będziesz kopiować ręcznie.
