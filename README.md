# 3 karty, dzięki którym AI zna Twój biznes

To darmowy pakiet z live **"Zbuduj własny system AI"** ([bartbakowski.com/webinary](https://bartbakowski.com/webinary)).

W środku masz przewodnika, który **przeprowadzi Cię przez zbudowanie 3 kart kontekstu**:

- **Karta strategiczna** - kim jesteś, do kogo mówisz, co sprzedajesz i jak z Tobą pracować (Twój profil: decyzje, energia, blokery, granice).
- **Karta wizualna** - jak wygląda Twój świat (kolory, fonty, nastrój).
- **Karta głosu** - jak AI ma pisać w Twoim imieniu.

Raz je robisz, a AI przestaje zgadywać: zna Twój biznes i brzmi jak Ty. W każdej rozmowie, nie tylko pod stronę internetową. Na końcu przewodnik składa z kart **Twój gotowy plik kontekstu (`moj-CLAUDE.md`)**, który wrzucasz do dowolnego projektu jako `CLAUDE.md` i AI zna Cię od pierwszej wiadomości.

---

## Jak zacząć (3 kroki)

### 1. Pobierz ten folder
Na górze strony GitHub kliknij zielony przycisk **Code -> Download ZIP**. Rozpakuj na pulpicie.

### 2. Otwórz go w Claude Code
Jeśli nie masz jeszcze Claude Code, na live pokazuję, jak go zainstalować (to jedna komenda). Otwórz w nim ten folder.

### 3. Napisz: `zacznijmy`
I tyle. Reszta dzieje się w rozmowie. Claude przywita Cię, wytłumaczy plan i poprowadzi krok po kroku, jedno pytanie po drugim. Zajmie to ok. 30-40 minut. Wypełnione karty zapisze w folderze `karty/`, a na końcu złoży z nich Twój gotowy plik kontekstu `moj-CLAUDE.md`.

---

## Nie masz Claude Code? Zrobisz to też w zwykłym chacie

Działa też w aplikacji Claude albo w ChatGPT. Otwórz plik **`START-w-chacie.md`** i wklej jego treść do chatu. Przewodnik ruszy tak samo, tylko karty będziesz kopiować ręcznie.

## Co jest w środku

```
trzy-karty-ai/
├── CLAUDE.md            <- instrukcja, którą Claude Code czyta sam
├── START-w-chacie.md    <- to samo do wklejenia w zwykłym chacie
├── karty/               <- tu powstają Twoje 3 karty
│   ├── karta-strategiczna.md
│   ├── karta-wizualna.md
│   └── karta-glosu.md
├── przyklad/            <- komplet wypełniony + gotowy plik kontekstu, żebyś widział efekt
└── moj-CLAUDE.md        <- powstaje na końcu: Twój kontekst do wrzucenia w dowolny projekt
```
